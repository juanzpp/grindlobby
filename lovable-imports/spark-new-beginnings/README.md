# Spark New Beginnings

Lovable project: `89a4b2a4-c6c6-4d8f-a4d2-9092eeaadd7b`

Historical single-screen GrindLobby prototype. Layout characteristics extracted from `src/routes/index.tsx`:

- 72px hub rail on the far left.
- Header with `GrindLobby Hub`, server-online state and `Buscar Partida` CTA.
- Live match card: Team Alpha vs Gringo Squad, Mirage, score 12:09.
- Stats card: K/D, win rate and Grind Points.
- Friends sidebar with user audio/video/settings controls.

This version is visibly Discord-like and its token set contains an old red competitive accent, so it must not replace the current GrindLobby identity. It is preserved only for individual interaction/layout ideas.

Generic shadcn boilerplate, generated files and binary favicon are intentionally omitted.
