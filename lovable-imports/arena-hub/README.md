# Arena Hub

Lovable project: `a42f68d4-4b65-4359-8e52-dfc6546b25e6`

Historical dashboard prototype preserved as a visual reference. Extracted authored concepts from `src/routes/index.tsx`:

- left navigation: Dashboard, Lobbies, Rank, Loja, Pro, Configurações;
- Admin/PRO status header;
- large rank panel (Ascendente IV / RP);
- active lobby list with mic states;
- audio device controls and screen action;
- dark black/navy + purple composition.

This project uses a generic Zap icon as branding and mock content. Neither should replace production branding/data. The current GrindLobby official example-07 asset remains authoritative.

Generic shadcn files and starter boilerplate are intentionally omitted.
